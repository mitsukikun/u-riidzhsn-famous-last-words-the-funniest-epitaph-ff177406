A program that writes one funny epitaph — a dead man's last words, carved in stone — to `/output/entry.txt`: three final messages for the living ("Tell my wife I was right. Tell my boss I was wrong. Tell the doctor I was early."), where the third beat lands a double meaning: early for the appointment, or early for the grave.

## Run it

```bash
python3 main.py
```
